# Arbion Business

Growth platform and digital growth system for dental clinics.

## Stack

- Next.js App Router
- React
- TypeScript
- Custom CSS design system

## Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Direction

Arbion Business is being built as a premium, technology-led growth platform for dental clinics. The public website is the first layer; the architecture will later expand into lead management, automation, analytics and a private clinic dashboard.
